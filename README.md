# 🌤️ Weather App - Open-Meteo API Integration

A Spring Boot application integrating with the Open-Meteo API to display current weather data.

## ✨ Features

- Country and city selection
- Current weather data from Open-Meteo
- Display of temperature and wind speed

## 🚀 Live Demo

**🌐https://weather-app-1-yka5.onrender.com**

## 🛠️ Local Development

``bash
./mvnw spring-boot:run
Open your browser and visit: http://localhost:8080
